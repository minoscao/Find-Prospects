# 远见 · 海外获客工作台

基于已确认的三张 Mockup 制作的本地可运行首版。当前是交互工作台与部分数据接口基础，不是已经具备全网自动获客能力的生产系统。

## 使用

双击 `启动软件.cmd`，或使用 Node.js 22+ 运行 `node server.js --production`，打开 http://127.0.0.1:4173 。仅监听本机，不对外网开放。

右上角「中 / EN」一键切换，选择保存在当前浏览器。公司名和原始来源保留原文。演示客户、跟进记录和计划也存放于当前浏览器 localStorage，不会上传。不同浏览器不共享记录。

## 已实现

- Dashboard：由当前名单计算的漏斗、任务和客户动态。
- 地图：OpenStreetMap 底图，可切换区域、点击绘制多边形、搜索区域内示例客户并去重加入名单。
- 筛选：初选、资料筛选、Shortlist、Finalist、剔除记录；网格/列表与社交平台筛选。演示模式支持阶段操作；真实客户不自动编造评分。
- 客户详情：来源事实与需求推测分开，Facebook、Instagram、LinkedIn、官网、Google Maps 身份网络，节点可点击检查关联依据。官网链接仅证明链接存在，不自动证明账号所有权。
- 素材计划：自动来源展示、关键词和说明、计划保存及 JSON 需求包导出。没有上传客户素材的入口，不包含软件一的生产功能。
- 跟进：本地记录、可编辑中英文模板草稿、人工确认意向后的交接包导出。不会发送消息或通知工厂。
- 中英界面切换与偏好持久化。

## 数据接入

1. Google Places：服务端 `/api/search` 已实现 Text Search New，密钥读取 `GOOGLE_MAPS_API_KEY`。复制 `.env.example` 为 `.env` 后填写自己的 key，启用对应 API 与计费，并重启服务。密钥不进入客户端代码或浏览器存储。当前每次最多请求20条，对矩形返回结果做多边形过滤，不承诺覆盖全区域商家。尚无真实 key，因此未验证真实响应与计费。
2. 官网链接：`/api/enrich` 从 API 提供的 HTTPS 官网提取 Facebook / Instagram / LinkedIn / YouTube / TikTok 对外链接，并保存来源和采集时间。限制公共 IPv4、固定 DNS 解析、禁止重定向、限制响应大小与超时。失败时保留已有资料。不是全网站爬虫，不读取登录内容。
3. 尚未实现：社交平台帖子、地图评论/图片全文、全网账号检索、自动 AI 需求分析和评分、邮件/社交发送与自动接待、软件一实际提交、多用户共享与后台定时任务。相应状态在界面标明未接入；不能仅靠 Google key 解锁这些能力。

当前机器网络限制：验收时 example.com 被本机 DNS/代理解析为 198.18.x.x 保留地址。官网采集的公共地址保护因此拒绝该请求，返回 WEBSITE_UNAVAILABLE。没有为了连通性放开内网访问；真实官网采集仍需在正常公共 DNS 或明确配置的安全出口环境验证。

## 验收记录

- 构建通过，4项自动测试通过：多边形筛选、阶段与排除统计、真实数据不伪造评分、导出保留来源。
- 内置浏览器检查：页面非空，无控制台错误；地图选区搜索示例名单、加入去重、客户详情、关系节点与待核验提示、中英切换、素材计划保存及刷新恢复通过。
- 桌面1280×720、原设计尺寸1586×992以及窄屏390×844检查；窄屏无横向溢出。原尺寸下内置截图存在裁切，因此最终截图使用实际1280×720视口。
- 对照设计检查侧栏与层级、浅色青绿配色、统计与筛选卡片、字号、详情抽屉；新增双语与身份网络，去掉上传入口。以工作区实际记录替代图片中的虚构数量，店铺图片用首字母标识替代。这不是像素级完全复刻。
- API检查：状态接口200；缺少Google key时503；第三方Origin被拒绝403；内网地址采集被拒绝。Google真实请求、社交平台内容及邮件发送尚未验收。

接口依据：https://developers.google.com/maps/documentation/places/web-service/text-search

## 开发

`npm install`；`npm run build`；`npm test`；`npm start`。

由于项目目录包含 `#`，构建脚本自动将源文件复制到 `%LOCALAPPDATA%/TentGrowth/runtime-v1` 构建，再输出到本项目 `dist`。初次会安装临时构建依赖；原始源代码始终保留在本项目。修改代码后需重新构建并刷新浏览器。

静态原型与代码的有意差异：数据量改为实际演示记录计算；没有虚构的店铺图片和客户 Logo，使用首字母标识；无 API 时底图使用 OpenStreetMap；增加身份网络和双语按钮；去掉人工上传与虚构的已发送数据。
